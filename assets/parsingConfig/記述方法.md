# 【完全版】水族館スクレイピング設定 JSON 記述マニュアル

本アプリは、ウェブサイトの構造変化に強い **Jsoup CSS セレクタ** を第一優先とし、特殊な API レスポンス向けに **正規表現（Regex）** を併用できるハイブリッド方式を採用しています。

---

## 1. JSON 1エントリーの推奨テンプレート

> [!TIP]
> `id` の指定は不要です。園館名・URL・各種 CSS セレクタを記述します。

```json
{
  "aquaName": "アクアパーク品川",
  "url": "https://www.aqua-park.jp/shinagawa/news/",
  "itemCssSelector": "li.news-item",
  "titleCssSelector": ".title",
  "urlCssSelector": "a@href",
  "publishedDateCssSelector": "time",
  "summaryCssSelector": ".text",
  "uniqueStrCssSelector": "span.data-id",
  "noticeBlockStart": "<ul class=\"news-list\">",
  "noticeBlockEnd": "</ul>",
  "noticeItemDelimiter": "</li>",
  "titleRegex": "<span class=\"title\">([\\s\\S]*?)</span>",
  "urlRegex": "<a href=\"([\\s\\S]*?)\"",
  "publishedDateRegex": "<time>([\\s\\S]*?)</time>",
  "summaryRegex": "<p class=\"text\">([\\s\\S]*?)</p>",
  "uniqueStrRegex": ""
}
```

---

## 2. JSON の全キー（Key）と意味一覧

### ① 基本情報

| キー名 (Key) | 必須 | 型 | 意味と役割 | 記述例 |
| :--- | :---: | :---: | :--- | :--- |
| **`aquaName`** | **必須** | 文字列 | 水族館名。アプリ内の表示や DB 保存に使われる正式名称。 | `"アクアパーク品川"` |
| **`url`** | **必須** | 文字列 | スクレイピング対象となる **お知らせ一覧ページの完全 URL**。 | `"https://example.com/news/"` |
| **`officialUrl`** | 任意 | 文字列 | 公式サイトのトップページ URL（省略時は空文字）。 | `"https://example.com/"` |
| **`type`** | 任意 | 文字列 | 園館種別（`"水族館"`, `"動物園"`, `"博物館"` 等）。 | `"水族館"` |
| **`region`** | 任意 | 文字列 | 地方区分（`"関東"`, `"近畿"`, `"中部"` 等）。 | `"関東"` |
| **`prefecture`** | 任意 | 文字列 | 都道府県名。 | `"東京都"` |
| **`latitude`** | 任意 | 数値 | 水族館の緯度（GPS 来館記録用）。 | `35.6288` |
| **`longitude`** | 任意 | 数値 | 水族館の経度（GPS 来館記録用）。 | `139.7365` |
| **`radius`** | 任意 | 数値 | GPS 判定半径（メートル。デフォルト: 250.0）。 | `250.0` |

---

### ② Jsoup CSS セレクタ（★最重要・メイン抽出ルール）

| キー名 (Key) | 必須 | 役割と指定ルール |
| :--- | :---: | :--- |
| **`itemCssSelector`** | **必須** | **1件の記事ブロック（かたまり）を特定するセレクタ**。<br>※この要素が複数個リストとして切り出されます。<br>例: `"li.news-item"`, `"article.post"`, `"div.notice-record"` |
| **`titleCssSelector`** | **必須** | 切り出した記事ブロックの **内側にあるタイトル要素** を指すセレクタ。<br>例: `".title"`, `"h3"`, `"a"`, `"p.heading"` |
| **`urlCssSelector`** | **必須** | 記事の **詳細リンク先 URL** を取得するセレクタ（`@href` を併用）。<br>例: `"a@href"`, `":root@href"` |
| **`publishedDateCssSelector`** | 任意 | **公開日・更新日** を指すセレクタ。<br>例: `"time"`, `"time@datetime"`, `".date"`, `".date:ownText"` |
| **`summaryCssSelector`** | 任意 | **本文や概要テキスト** を指すセレクタ（一覧になければ空文字 `""`）。<br>例: `".summary"`, `"p.text"`, `""` |
| **`uniqueStrCssSelector`** | 任意 | 記事の一意な識別子（記事 ID 等）があれば取得するセレクタ（通常は `""` で OK）。<br>例: `"span.data-id"`, `""` |

---

### ③ 正規表現（Regex）フォールバック設定

HTML サイトで CSS セレクタがマッチしなかった場合や、特殊な API エンドポイント用。

| キー名 (Key) | 役割と指定ルール |
| :--- | :--- |
| **`noticeBlockStart`** | ニュース一覧全体の開始目印文字列（例: `"<ul class=\"news\">"`）。 |
| **`noticeBlockEnd`** | ニュース一覧全体の終了目印文字列（例: `"</ul>"`）。 |
| **`noticeItemDelimiter`** | 各記事の区切り目印文字列（例: `"</li>"`）。 |
| **`titleRegex`** | タイトルを抽出する正規表現（例: `"<h3 class=\"title\">(.*?)</h3>"`）。 |
| **`urlRegex`** | URL を抽出する正規表現（例: `"href=\"(.*?)\""`）。 |
| **`publishedDateRegex`** | 日付を抽出する正規表現（例: `"<time>(.*?)</time>"`）。 |
| **`summaryRegex`** | 概要を抽出する正規表現（例: `"<p class=\"text\">(.*?)</p>"`）。 |
| **`uniqueStrRegex`** | 記事 ID 抽出の正規表現（通常は空文字 `""`）。 |

## 3. CSS セレクタの完全記法ルール

Jsoup は標準の CSS3 セレクタに加え、jQuery 由来のセレクタや本アプリ専用の独自記法を解釈できます。

### 1. 本アプリ専用の拡張構文（独自ルール）

| 記号・構文 | 意味 | 具体例 | 抽出結果 |
| :--- | :--- | :--- | :--- |
| **`@属性名`** | 要素の **属性値（attribute）** を直接取得する | `a@href` | `<a>` タグのリンク先 URL（相対パスは自動で絶対 URL 化） |
| | | `time@datetime` | `<time datetime="2026-05-01">` の `"2026-05-01"` |
| | | `img@src` | 画像の URL |
| **`:root`** | 切り出された **記事ブロック自身（親要素そのもの）** を対象にする | `:root@href` | 記事枠自体が `<a href="...">` の場合に自身の URL を取得 |
| **`:ownText`** | 子要素を除き、**その要素自身が直接持つテキストのみ** 抽出する | `p:ownText` | `<p>2026.05.01<span>NEW</span></p>` から `"NEW"` を除外した `"2026.05.01"` のみ取得 |

---

### 2. 基本セレクタ

| 記号 | 意味 | 記述例 | 対象となる HTML 例 |
| :---: | :--- | :--- | :--- |
| **`.`** | クラス名（class） | `.news-item` | `<div class="news-item">` |
| **`#`** | ID 名（id） | `#news-list` | `<ul id="news-list">` |
| （なし） | タグ名 | `article`, `time`, `h3` | `<article>`, `<time>`, `<h3>` |
| **` `**（半角空白） | **子孫要素**（内側の全階層） | `ul li a` | `<ul>` の内側にある任意の深さの `<a>` |
| **`>`** | **直下の子要素**（1階層目のみ） | `div.wrapper > div` | ラッパー直下の `div` のみ（孫 `div` は除外） |
| **`,`**（カンマ） | **OR 条件**（複数マッチ） | `h3, h4` | `<h3>` または `<h4>` のいずれか |

---

### 3. 属性セレクタ `[...]`

タグ自身が持っている **属性値（attribute）** で絞り込みます。

| 構文 | 条件 | 記述例 | マッチする要素の例 |
| :--- | :--- | :--- | :--- |
| **`[属性]`** | その属性が存在する | `a[target]` | `<a href="..." target="_blank">` |
| **`[属性="値"]`** | 属性値が **完全一致** | `span[data-type="title"]` | `<span class="data-field" data-type="title">` |
| **`[属性*="値"]`** | 属性値に **特定の文字列を含む** | `a[href*="/news/"]` | `<a href="/japan/news/detail.html">` |
| **`[属性^="値"]`** | 属性値が **指定文字から始まる** | `a[href^="https://"]` | 絶対 URL のリンクのみ |
| **`[属性$="値"]`** | 属性値が **指定文字で終わる** | `a[href$=".pdf"]` | PDF リンクのみ |

---

### 4. 階層・包含セレクタ（`:has` 等）

親要素や位置関係を指定するセレクタです。

| 構文 | 意味 | 記述例と解説 |
| :--- | :--- | :--- |
| **`:has(セレクタ)`** | **「指定した子要素を含んでいる親要素」** を絞り込む | `div:has(span.title)`<br>→ 内側に `span.title` を持っている `div` だけを選択する。<br>※入れ子 `div` がある場合、親と子の両方にヒットして重複抽出の原因になるため、**専用クラス名がある場合は `div.notice-record` のように直接クラス名を指定するのが原則**です。 |
| **`:not(セレクタ)`** | 指定した条件を **除外** する | `a:not(.external)`<br>→ class に `external` を持たない `<a>` タグのみ取得 |
| **`:first-child`** | 最初の兄弟要素 | `li:first-child` |
| **`:nth-child(n)`** | n 番目の要素 | `tr:nth-child(2)` |

## 4. 手動登録の実践パターン集

### パターン A: 記事枠が `<li>` で、中にリンクがある場合（超定番）
```html
<li class="news-item">
    <span class="date">2026.05.01</span>
    <a href="/news/detail123.html" class="title">イルカの赤ちゃん誕生</a>
</li>
```
- `itemCssSelector`: `"li.news-item"`
- `titleCssSelector`: `".title"`（または `"a"`）
- `urlCssSelector`: `"a@href"`
- `publishedDateCssSelector`: `".date"`

---

### パターン B: 記事枠そのものが `<a>` リンク（カード形式）
```html
<a href="/news/detail456.html" class="news-card">
    <time datetime="2026-05-01">2026/05/01</time>
    <h3 class="heading">ペンギンのお散歩</h3>
</a>
```
- `itemCssSelector`: `"a.news-card"`
- `titleCssSelector`: `"h3.heading"`
- `urlCssSelector`: `":root@href"`（★自分自身の href を取る）
- `publishedDateCssSelector`: `"time@datetime"`（または `"time"`）

---

### パターン C: 日付にバッジが混ざっている場合
```html
<div class="notice-record">
    <p class="date">2026.05.01<span class="badge">NEW</span></p>
    <a href="/detail.html">新着情報</a>
</div>
```
- `itemCssSelector`: `"div.notice-record"`
- `publishedDateCssSelector`: `".date:ownText"`（★子要素の "NEW" を除外して "2026.05.01" だけ取得）
