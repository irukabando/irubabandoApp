本アプリのパース設定 JSON（`aquaInfoParsingConfigs.json` 等）で指定できる **CSS セレクタの記載ルール** を一覧にまとめました。

本アプリは、標準の **Jsoup（CSS）セレクタ** に加え、HTML スクレイピングを簡単にするための **独自拡張ルール（`@`, `:ownText`, `:root`）** をサポートしています。

---

### 1. 独自拡張ルール（本アプリ専用の便利構文）

HTML タグの属性値や、余計な子要素を除いたテキストをピンポイントで取得するための構文です。

| 記号・構文 | 意味・役割 | 具体的な記述例 | 抽出される結果 |
| :--- | :--- | :--- | :--- |
| **`@属性名`** | 指定要素の **属性値（attribute）** を抽出する | `a@href` | `<a>` タグのリンク先 URL |
| | | `time@datetime` | `<time datetime="2026-05-01">` の `"2026-05-01"` |
| | | `img@src` | 画像の画像 URL |
| **`:root`** | 切り出された **記事ブロック自身（親要素そのもの）** を対象にする | `:root@href` | 記事枠自体が `<a href="...">` の場合にその URL を取得 |
| **`:ownText`** | 子要素のテキストを除き、**その要素自身が直接持つテキストのみ** を抽出する | `p:ownText` | `<p>日付<span>NEW</span></p>` から `"NEW"` を除いた `"日付"` のみ取得 |

---

### 2. 基本の CSS セレクタ記号（Jsoup 標準）

HTML のどの要素（タグ・クラス・ID）を狙うかを指定する記号です。

| 記号 | 意味 | 具体的な記述例 | 対象となる HTML 例 |
| :---: | :--- | :--- | :--- |
| **`.`** | **class名** で指定 | `.news-item`<br>`.title` | `<div class="news-item">`<br>`<span class="title">` |
| **`#`** | **id名** で指定 | `#main-news`<br>`#notice-list` | `<ul id="main-news">` |
| （なし） | **タグ名（HTMLタグ）** で直接指定 | `article`<br>`time`<br>`h3` | `<article>`, `<time>`, `<h3>` |
| **` `**（半角スペース） | **子孫要素**（内側にある要素） | `article a`<br>`.news-box .date` | `<article>` の内側にある `<a>`<br>`.news-box` の内側にある `.date` |
| **`>`** | **直下の子要素**（1階層だけ下） | `ul > li`<br>`.list > a` | `<ul>` の直下にある `<li>` |
| **`,`**（カンマ） | **OR 条件**（いずれかにマッチ） | `h3, h4`<br>`.title, .heading` | `<h3>` または `<h4>` |

---

### 3. 属性セレクタ（特定の属性を持つタグを絞り込む記号）

同じタグ名やクラス名でも、「特定の URL を含むリンク」や「特定の属性がある要素」だけを狙い撃ちする記法です。

| 記号・構文 | 意味 | 具体的な記述例 | 対象となる HTML 例 |
| :--- | :--- | :--- | :--- |
| **`[属性]`** | その属性を持っている | `a[target]` | `<a href="..." target="_blank">` |
| **`[属性="値"]`** | 属性値が **完全一致** | `span[itemprop="name"]` | `<span itemprop="name">` |
| **`[属性*="値"]`** | 属性値に **特定の文字列を含む** | `a[href*="news"]` | `href` に `"news"` が含まれるリンク |
| **`[属性^="値"]`** | 属性値が **指定文字から始まる** | `a[href^="/event/"]` | `href` が `"/event/"` で始まるリンク |
| **`[属性$="値"]`** | 属性値が **指定文字で終わる** | `a[href$=".pdf"]` | PDF ファイルへのリンク |

---

### 4. 組み合わせの実践例（JSON でよく使う記述パターン）

JSON の各フィールドにおける代表的な指定例です：

#### ① 1記事のかたまりを切り出す（`uniqueStrCssSelector`）
- `li.news-list__item` → `class="news-list__item"` を持つ `<li>` 要素
- `article.post` → `class="post"` を持つ `<article>` 要素
- `a.card` → 記事枠自体がリンクになっている `<a class="card">` 要素

#### ② タイトルを取得する（`titleCssSelector`）
- `.title` → クラス名が `title` の要素のテキスト
- `h3.heading` → クラス名が `heading` の `<h3>` 見出しテキスト
- `a` → リンク内のテキスト

#### ③ URL を取得する（`urlCssSelector`）
- `a@href` → 子要素にある `<a>` タグの `href` 属性値
- `:root@href` → 切り出した要素自身（`uniqueStrCssSelector`）が `<a>` タグの場合の `href` 属性値

#### ④ 日付を取得する（`dateCssSelector`）
- `time` → `<time>2026.05.01</time>` のテキスト
- `time@datetime` → `<time datetime="2026-05-01">` の `datetime` 属性値
- `span.date:ownText` → 余計なバッジタグ等を含まない日付テキストのみ

このように、**「標準の CSS セレクタ（`.`, `#`, `タグ名`, `>`）」で要素を絞り込み、末尾に「`@属性名` や `:ownText`」を付けることで中身を取り出す** のが本アプリのルールとなっています。
